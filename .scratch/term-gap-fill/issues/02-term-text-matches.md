# 02 — 術語補標

**What to build:** 遊戲漏標的術語也搜得到。新增維護者清單「術語比對清單」,每筆是術語 id 加上陸服與台服各自的比對字串,初始內容是規格表格的 17 筆。建置時,術語比對清單與補充關鍵字清單的字串合在同一輪比對,規則同補充關鍵字:整段純文字、可跨越樣式標記、較長的優先、已有標記的字不重疊、補上的標記不保留樣式。清單裡的 id 不是會成為關鍵字的戰鬥術語(ba. 開頭、不在不當關鍵字的術語清單)時,建置發警告,這筆不比對。補上的標記和官方標記走同一條效果類型判定與待複核流程。

完成後:台服模式搜「束縛」出現裁度、搜「暈眩」出現琴柳、斥罪、烏爾比安;搜「元素損傷」出現特性寫「可以造成元素損傷」的幹員。
