# 01 — 兩服一致時的覆寫差異警告

**What to build:** 某段敘述的台服文字標記後和陸服一致時,建置照現有規則讓台服沿用陸服的效果類型。這張票在這條路上加一道檢查:建置仍以台服純文字的雜湊查台服自己的覆寫判定,只要有任何一個關鍵字的台服覆寫和沿用來的陸服效果類型不同,就發建置警告,指出幹員、出處、關鍵字與兩邊的判定。效果類型照樣沿用陸服的。這張先做,下一張的術語補標讓某些敘述變成兩服一致時,既有判定的改變就會立刻浮現,不會悄悄發生。

規格:[spec.md](../spec.md)(實作決策「台服與陸服一致的判斷」、決定「補標讓台服與陸服變成一致時,要不要防既有判定改變?」)。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 台服覆寫判定相同,或台服沒有覆寫判定時,不發警告
- [x] 效果類型照樣沿用陸服的,搜尋結果不變
