# 01 — 減抗關鍵字

**What to build:** 關鍵字面板的減益分組第二行最前面(虛弱之前)出現補充關鍵字「減抗」。點了之後列出敘述中降低敵人法術抗性的幹員(例如伊芙利特「攻擊範圍內的敵軍法術抗性-40%」、夜煙、邏各斯「法術抗性-10」),陸服與台服文字都命中;同一段同時降低防禦與法抗的敘述(初雪、引星棘刺)也命中減抗。游標停在命中處看得到標為非官方的定義「降低敵人的法術抗性。」。新增的命中配對照現有流程判定效果類型:規則先判,再於 session 內複核寫進覆寫檔(ADR 0001、0002)。稽核種子字用「法術抗性/法术抗性」,可疑處經維護者過目後接受。規格見 `.scratch/def-res-down/spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 補充關鍵字清單新增 id `resdown`、名稱「減抗」、定義「降低敵人的法術抗性。」;陸服比對字串「法术抗性-」,台服「法術抗性-」。比對機制不變(同友方技力回復等現有補充關鍵字)
- [ ] 關鍵字分組:減益分組第二行最前面,之後是虛弱、脆弱、物理脆弱、法術脆弱、元素脆弱(同控場分組:補充關鍵字排在行首)
- [ ] 稽核種子字清單新增 `resdown`:「法術抗性」「法术抗性」;跑稽核,把可疑處(陸服約 35 處,台服相近)列給維護者過目,接受進已知可疑清單;過目時發現的新減抗寫法補進比對字串。重建後沒有未知的可疑處與未知警告
- [ ] 新增的減抗配對跑完 session 內效果類型複核,決定寫進覆寫檔;降低敵人法抗的判為施加。重建後待複核配對為 0
- [ ] Vitest(建置 → 查詢,沿用補充關鍵字現有測試的手寫資料與實際清單):「法術抗性-」簡中、繁中各一段會命中減抗並高亮;「無視…法術抗性」不命中
- [ ] 重建實際索引,列出減抗命中的幹員給維護者過目(預期兩服各 11 位,見規格「其他備註」的指令),確認沒有明顯漏網或誤判
- [ ] e2e:減抗在減益分組第二行最前面、虛弱之前;點了之後伊芙利特在結果裡;游標停在命中處看得到「降低敵人的法術抗性。」與「非官方」
