# 02 — 減防關鍵字

**What to build:** 關鍵字面板的減益分組第二行最前面出現補充關鍵字「減防」,排在減抗之前。點了之後列出敘述中降低敵人防禦力的幹員,涵蓋「防禦力-」(流星、巫戀、伊芙利特)、「防禦力下降」(黑、鴻雪)、「防禦力降低」(貝洛內)、召喚物的「降低被阻擋單位的防禦力」(迷迭香),以及陸服珊比的「防禦力額外-」;陸服與台服文字都命中。降低自身防禦當代價的敘述(銀灰 S3、真理、纏丸、山)雖然被比對字串命中,但在效果類型複核時判為無效果類型,不列入結果。無視防禦、偷取防禦、只提到防禦而沒有降低的敘述都不命中。游標停在命中處看得到標為非官方的定義「降低敵人的防禦力。」。稽核種子字用「防禦力/防御力」,可疑處經維護者過目後接受。規格見 `.scratch/def-res-down/spec.md`。

**Blocked by:** 01(兩張票改同一份補充關鍵字清單、分組、種子字清單與覆寫檔)
