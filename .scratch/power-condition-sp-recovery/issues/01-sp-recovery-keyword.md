# 01 — 技力回復關鍵字

**What to build:** 關鍵字面板的增益分組裡,緊接在鼓舞後面出現補充關鍵字「技力回復」。點了之後列出敘述中會使自身或友方瞬間回復技力(例如「額外回復2點技力」「擊殺者技力+2」)、提升技力回復速度(例如「技力自然恢復速度+0.2/秒」)或提高初始技力(例如荒蕪拉普蘭德、凜御銀灰)的幹員,陸服與台服文字都命中;只提到技力、沒有回復的敘述(例如「技力滿時可使用」)不命中。游標停在關鍵字上看得到標為非官方的定義「使自身或友方立即獲得技力、提高初始技力,或提升技力的回復速度。」。新增的命中配對照現有流程判定效果類型:規則先判,再於 session 內複核寫進覆寫檔(ADR 0001、0002),讓實際索引裡技力回復的配對都有效果類型。規格見 `.scratch/power-condition-sp-recovery/spec.md`。

**Blocked by:** None (can start immediately)
