# 03 — 勢力條件的周邊顯示與配色

**What to build:** 勢力條件融入頁面其他地方。什麼都沒選時提示文字改成「點選關鍵字、職業或勢力開始搜尋」。勢力 chip 用職業 chip 的顏色(石板藍灰淡底 + 同色框字),面板上選取的勢力鈕用石板藍灰實心(和篩選列選取的職業鈕相同),與選取時是藍色的關鍵字鈕分得開。勢力 chip 依面板順序排列,不依點選先後。窄螢幕抽屜鈕文字與抽屜標題維持「關鍵字」,計數 = 已選關鍵字數 + 勢力條件數。無結果清單依職業 → 勢力 → 搜尋條件 → 伺服器 → 星級列出,沒有內容的項目不列(伺服器一律列出)。規格見 `.scratch/power-condition-sp-recovery/spec.md`。
