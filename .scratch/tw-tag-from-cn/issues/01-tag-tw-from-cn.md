# 01 — 照陸服補標台服術語

**What to build:** 台服模式搜「凋亡損傷」時,查得到 PhonoR-0(我方版)和菲萊(敵方版),天賦 1 的「凋亡損傷」也會高亮。建置時,陸服有官方標記、台服沒標的術語,用這個術語的台服官方名稱(去掉「·我方」後綴)在台服純文字裡找,照陸服的 id 補上標記,所有還沒標記的出現處都標。兩服都只數官方標記,也就是術語比對清單與補充關鍵字之前的標記,以標記數計;只由比對清單補上的術語不照陸服補。照陸服補標做在比對清單與補充關鍵字之前。同一個台服名稱對到陸服兩個不同 id 時,這個名稱不標,發建置警告。全部標記完成後,某個 id 的台服最終標記數仍少於陸服官方標記數時,發「找不到名稱」的建置警告;已經因同名不同 id 發過警告的不再重複發。補完兩服一致的敘述照現有規則處理:台服沿用陸服的效果類型,陸服模式顯示台服文字。
